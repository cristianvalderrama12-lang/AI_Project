# AI_Project - Actividad Formativa GitHub Copilot

## Descripción del Proyecto
Implementación de un sistema de recomendación básico en Python utilizando la librería `scikit-learn` y el asistente de inteligencia artificial GitHub Copilot integrado en Visual Studio Code.

---

## Paso a Paso del Proceso Realizado

### 1. Creación y Configuración del Repositorio en GitHub
Se creó el repositorio remoto `AI_Project` en GitHub con visibilidad pública e inicializado con un archivo `README.md` para alojar el proyecto.

<img width="921" height="443" alt="image" src="https://github.com/user-attachments/assets/da1d6fb6-3c4c-476e-9fde-aba9a4a47086" />

### 2. Clonación y Configuración en Visual Studio Code
Se vinculó la cuenta de GitHub con Visual Studio Code, se activó la extensión GitHub Copilot y se clonó el repositorio localmente en el equipo.

<img width="921" height="488" alt="image" src="https://github.com/user-attachments/assets/e6898efe-e266-4751-8e37-7cf54b8b5b15" />

### 3. Desarrollo del Sistema de Recomendación (`recommendation_system.py`)
Se creó el archivo `recommendation_system.py` y, apoyado por GitHub Copilot, se desarrolló el algoritmo de clasificación utilizando `KNeighborsClassifier`, `pandas` y `numpy` para entrenar el modelo y generar recomendaciones.

<img width="921" height="488" alt="image" src="https://github.com/user-attachments/assets/4e22a13c-1322-40d7-9b1f-bc57fbd292e0" />

### 4. Sincronización con Git (`Add`, `Commit` y `Push`)
Mediante la terminal integrada de Visual Studio Code se configuró la identidad de usuario en Git (`user.name` y `user.email`) y se subieron los cambios al repositorio remoto mediante `git add .`, `git commit` y `git push`.
